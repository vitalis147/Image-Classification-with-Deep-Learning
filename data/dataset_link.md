Here is the link to the Google Street View House Numbers Dataset[http://ufldl.stanford.edu/housenumbers/]

Format 2, which was a cropped version of the house numbers, was downloaded for this project. <br>
Both the train and test set are saved as .mat, a dictionary with **X** and **y** as the keys respectively. <br>
**X** is a 4D matrix(H, W, c, N) containing 32 x 32 pixel images while **y** is row vector holding the class labels.
